# password-manager

一个本地离线的 Chrome 密码管理插件（MV3），支持：

- 主密码解锁（端侧加密存储在硬盘上，数据保存在 `chrome.storage.local`）
- 账号密码录入、查询、编辑、删除
- 一键复制用户名/密码
- 解锁后可导入/导出当前数据为 JSON

## 安装（开发者模式）

1. 打开 Chrome，进入 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本仓库中的目录：`extension/`

## 使用

1. 点击浏览器工具栏里的插件图标
2. 首次使用：设置主密码创建 Vault
3. 之后使用：输入主密码解锁
4. 在 Vault 中：
   - `Add` 新增条目（默认会用当前标签页的 origin 预填 URL）
   - `Import` 导入 JSON
   - `Export` 导出 JSON
   - `U` 复制用户名，`P` 复制密码
   - `✎` 编辑，`×` 删除

## 安全说明

- 数据仅存本地：不做任何联网同步
- 存储形态：加密后的 Vault（PBKDF2(SHA-256) 派生密钥 + AES-GCM 加密）
- 解锁态：每次打开浏览器后首次使用需要解锁一次；解锁密钥保存在浏览器会话存储中（`chrome.storage.session`），关闭浏览器后自动清除
- 主密码无法找回：遗忘主密码将无法解密已有数据（需要清空扩展存储后重新创建）
